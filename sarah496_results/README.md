## File Structure

Each JSON file corresponds to one source PDF and contains:

```json
{
  "pdf_name": "Document_Name",
  "total_pages": 1,
  "metadata": {
    "Source-File": "/path/to/source.pdf",
    "olmocr-version": "0.3.4",
    "pdf-total-pages": 117,
    "total-input-tokens": 194220,
    "total-output-tokens": 30629,
    "total-fallback-pages": 0
  },
  "pages": [
    {
      "id": "...",
      "text": "...full OCR text from all pages concatenated...",
      "added": "...",
      "created": "...",
      "source": "olmocr",
      "metadata": {...},
      "attributes": {}
    }
  ]
}
```

## Key Fields

- **pdf_name**: Source PDF filename (without .pdf extension)
- **metadata.pdf-total-pages**: Number of pages in the original PDF
- **metadata.total-input-tokens**: Tokens sent to the model
- **metadata.total-output-tokens**: Tokens generated by the model
- **pages[0].text**: Complete OCR text from all pages (markdown-formatted)
